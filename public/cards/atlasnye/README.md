# Mazzo Atlasnye

Grafica vettoriale delle carte russe Atlasnye, basata sui disegni storici di
A. I. Charlemagne. Il file contiene l'intero mazzo, comprese tutte le 36 carte
da Durak (6-Asso per quattro semi) e i dorsi.

- Autore della versione SVG: Dmitry Fomin
- Licenza: CC0 1.0 Universal / pubblico dominio
- Fonte originale: https://commons.wikimedia.org/wiki/File:Atlasnye_playing_cards_deck.svg
- Packaging SVG con identificatori carta: https://github.com/ninjaro/kcuckoounter

Il gioco Preferans utilizza le 32 carte dal 7 all'Asso. Le quattro carte di
valore 6 restano incluse per la futura modalità Durak.
